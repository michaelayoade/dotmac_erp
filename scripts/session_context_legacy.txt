# Legacy unscoped sessions under scripts/ — a RATCHET, not an approval.
#
# Every line is a script that opens a raw `SessionLocal()`, so it primes
# neither tenant layer: no ORM listener, no RLS GUC. For a batch script that
# is not fail-closed, it is fail-SILENT — zero rows, exit 0, "job succeeded".
#
# This list is deliberately NOT the `# session-context: allow` marker. That
# marker means "reviewed and correct". This file means "known-wrong,
# grandfathered, must shrink". Do not migrate an entry to the marker to make
# the build pass.
#
# The guard fails if a file here stops matching its count — in EITHER
# direction. Fixing one, archiving one, or deleting one requires editing this
# file, so progress is recorded rather than assumed.
#
# Removing a line is the goal. There are three legitimate ways:
#   1. It is a one-off that has already run -> `git mv` it to scripts/archive/
#      (archive/ is out of scan scope, so the entry becomes stale and must go).
#   2. It is a recurring operation -> move the decision into a service and
#      invoke it from app/tasks/, which already uses session_for_org.
#   3. It genuinely still needs to run by hand -> open the session via
#      `session_for_org(org_id)` or `cross_org_session()`.
#
